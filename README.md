# CampusHub

CampusHub est une plateforme web conçue pour faciliter la vie étudiante en regroupant des informations, ressources et services sur un même site.

## Fonctionnalités

- Accueil moderne
- Navigation intuitive
- Présentation des services du campus
- Design responsive

## Technologies utilisées

- HTML5
- CSS3
